# Marketplace — локальная версия для проверки

## Запуск на компьютере

Требуется Node.js 18.17+ (рекомендуется Node.js 20).

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Приложение работает в обычном браузере и в Telegram Mini App.

## Где хранятся данные

Объявления, избранное, жалобы, отзывы и выбранная роль сохраняются в `localStorage` текущего браузера на текущем устройстве. Серверная база данных не подключена, поэтому данные не синхронизируются между устройствами и браузерами. Очистка данных сайта в настройках браузера удалит эти записи.

## Важно для проверки

- Кнопка «Написать продавцу» открывает Telegram-профиль из username в объявлении.
- Начальные продавцы и объявления — тестовые записи; замените usernames на реальные Telegram usernames, чтобы проверить контакт.
- Локальное хранение не является безопасной авторизацией. Роли и модерация доступны только для проверки интерфейса и не должны использоваться для настоящих сделок.
- Загрузка фотографий в этой версии по-прежнему представлена упрощённым интерфейсом, а не серверным хранилищем.
- Для общего публичного маркетплейса понадобятся серверная авторизация Telegram, API и база данных.

## Деплой

Можно загрузить файлы проекта в GitHub и импортировать репозиторий в Vercel. Помните: даже после деплоя `localStorage` остаётся отдельным для каждого браузера и устройства.
